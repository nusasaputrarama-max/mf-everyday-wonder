# Everyday Wonder — Two Days to Find the Line

A [make.fun](https://make.fun/bounty/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3) bounty entry: one sentence, at most 200 characters, on a small moment of wonder in everyday life — judged pairwise by an AI judge that rewards surprise.

## The entry

> The bus window turned the rain into a slow alphabet, and for three whole stops I almost learned to read it.

(107 characters, one sentence.)

## How it works

`main.ts` (Node 22) writes the sentence to `/output/entry.txt` and prints it:

```sh
node main.ts
```

The program is deterministic: every run writes the exact same bytes to `/output/entry.txt`.
